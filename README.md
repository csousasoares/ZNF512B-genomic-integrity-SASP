# Reanalysis of ZNF512B Knockdown RNA-seq: Senescence & Inflammation Signatures

A reanalysis of public RNA-seq data from the paper **"ZNF512B protects critical regulatory regions to safeguard long term genomic integrity"**. The transcription factor ZNF512B safeguards genome integrity at key regulatory regions, and its loss is linked to senescence and inflammation-associated gene expression. This repository focuses on characterising the senescence-associated expression profile after ZNF512B knockdown in human fibroblasts.

## Overview

The workflow starts from HISAT2-aligned BAM files and ends with differential expression and gene set enrichment results:

```
fastp -> HISAT2 -> featureCounts (R) -> DESeq2 (Python) -> GSEA (Python)
01_featureCounts.R   02_deseq2_and_GSEA.ipynb
```

| Step | Tool | Purpose |
|------|------|---------|
| 1 | `Rsubread::featureCounts` | Obtained gene-level raw counts from BAM files (hg38 built-in annotation) |
| 2 | `PyDESeq2` | Differential expression, siZNF512B vs Control |
| 3 | `GSEApy` (`prerank`) | GSEA on Hallmark Gene Sets and the SenMayo senescence signature |

## Repository Contents

| File | Description |
|------|-------------|
| `01_featureCounts.R` | R script that counts reads per gene from the BAM files, converts Entrez IDs to gene symbols, and writes a raw count matrix. |
| `02_deseq2_and_GSEA.ipynb` | Python notebook that loads the counts, filters low-expression genes, runs PyDESeq2, makes a volcano plot, and runs GSEA (Hallmark and SenMayo). |

## Requirements

### R (step 1)
Managed with [`renv`](https://rstudio.github.io/renv/); the script calls `renv::restore()` to install the versions recorded in `renv.lock`. Packages used:

- `Rsubread`, `Rsamtools`
- `AnnotationDbi`, `org.Hs.eg.db`
- `stringr`, `readr`

### Python (step 2)
The notebook was run with a kernel named `bioinformatic_analyses`. Packages used:

- `pandas`, `numpy`
- `pydeseq2`
- `gseapy`
- `lets-plot`
- `ipython` / `jupyter`


## Usage

### 1. Generate the count matrix

```bash
Rscript 01_featureCounts.R
```

This script:

1. Restores the R environment with `renv`.
2. Inspects a BAM header to check chromosome naming against the annotation.
3. Runs `featureCounts` on all BAMs in `input_data/2_hisat2/` with the built-in hg38 annotation (single-end, unstranded, 8 threads).
4. Shortens sample names (e.g. `siZNF512B_R2`) and maps Entrez IDs to gene symbols, dropping unmapped genes.
5. Writes `output_data/feature_counts/raw_counts.tsv` and a `sessionInfo()` log.

### 2. Run differential expression and GSEA

Open and run the notebook:

```bash
jupyter lab 02_deseq2_and_GSEA.ipynb
```

The notebook:

1. **Loads counts** and builds a sample metadata table (siZNF512B vs Control, fibroblasts).
2. **Filters** genes, keeping those with more than 10 counts in at least 2 samples.
3. **Runs PyDESeq2** with design `~Treatment` and contrast `siZNF512B` vs `Control`. Cook's cutoff and independent filtering are disabled, since low-abundance genes were already filtered manually.
4. **Inspects genes of interest**: SASP/inflammation markers (e.g. `IL6`, `CXCL8`), cell cycle genes (`FOXM1`, `MKI67`, `LMNB1`), p53 targets and CDK inhibitors (`CDKN1A`, `MDM2`, `CDKN2A`, `CDKN2B`), and the knockdown target itself.
5. **Plots a volcano plot** (padj < 0.05, |log2FC| > 1).
6. **Runs GSEA** with `gseapy.prerank` on genes ranked by log2 fold change (10,000 permutations, multilevel method, seed 6) against:
   - **MSigDB Hallmark 2020** gene sets, summarised in a lollipop plot of significant terms (FDR < 0.05).
   - **SenMayo**, a senescence-associated gene signature, with an enrichment plot.

## Outputs

- **Raw counts**: gene symbol x sample matrix (`raw_counts.tsv`)
- **DESeq2 results**: log2 fold changes, p-values, and adjusted p-values for all tested genes
- **GSEA results**: Hallmark enrichment table (NES, FDR q-values)
- **Figures**: volcano plot, Hallmark NES plot, SenMayo enrichment plot

## Key Finding

ZNF512B knockdown in primary fibroblasts leads to a robust upregulation of senescence- and inflammation-associated signatures, consistent with the original paper. Notably, p53 targets such as `CDKN1A` and `MDM2`, as well as `CDKN2A`, were not clearly upregulated despite the strong SASP response.

## Notes and Caveats

- **Upstream steps are not included.** Read trimming (fastp) and alignment (HISAT2) must be done beforehand; this repo starts from sorted BAM files in `input_data/2_hisat2/`.
- **Sample metadata is hard-coded** in the notebook (two siZNF512B, then two Control). It is assigned to samples by position, so check that the column order in `raw_counts.tsv` matches before running DESeq2.
- **Run order:** the volcano plot cell saves into `output_data/gsea_results/`, but that folder is only created later in the notebook. If it doesn't exist yet, create it first or run the `os.makedirs` cell earlier.
- The R script assumes **single-end, unstranded** reads. Adjust `isPairedEnd` and `strandSpecific` in `featureCounts()` for other library types.
- The input `renv.lock` and `senmayo_gene_set.txt` files need to be supplied by you.
